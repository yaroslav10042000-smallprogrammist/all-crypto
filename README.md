## 1. Введение
`all_crypto.h` — это монолитная библиотека, содержащая в себе всё необходимое для безопасной работы с данными: от классических хешей (MD5, SHA-1) и современных стандартов (SHA-3, Ed25519, AES-GCM) до ГОСТов (Стрибог, Кузнечик, Магма) и утилит (Base64, BigInt, файловая система).

Библиотека разработана с упором на **автономность**: вам не нужно устанавливать OpenSSL, libsodium или подключать CMake. Достаточно просто скопировать один файл в проект.

---

## 2. Архитектура библиотеки
Библиотека разделена на пространства имен (namespaces), чтобы избежать конфликтов:

| Пространство имен | Назначение |
| :--- | :--- |
| `_` | Внутренние утилиты (конвертация, HEX, работа с байтами) |
| `rand_` | Базовый быстрый ГПСЧ (XORShift128+) |
| `rand_pp` | Продвинутые ГПСЧ (RC4, MT19937, PCG, ChaCha20) |
| `_bigint` | Арифметика произвольной точности (BigNum) |
| `_sha256`, `_sha512`, `_sha3` | Ядра хеш-функций (сырые байты) |
| `_stribog` | Ядро ГОСТ Р 34.11-2012 (Стрибог) |
| `_aes`, `_gcm` | Симметричное шифрование AES-256 |
| `_rsa`, `_ed25519` | Асимметричная криптография |
| `fs_` | Файлы, буферы, `UserStore` |
| `perlin_` | Генератор шума Перлина (для графики/карт) |

## 3. Быстрый старт
```cpp
#include "all_crypto.h"
#include <iostream>

int main() {
    std::string text = "Termux Crypto";
    
    // 1. Хеш
    std::cout << "SHA-512: " << sha512(text) << "\n";
    
    // 2. Шифрование
    std::vector<uint8_t> key(32, 0x42); // 256-битный ключ
    auto cipher = aes256_gcm_encrypt(_::B(text), key);
    
    // 3. Подпись
    auto kp = _ed25519::keygen();
    auto sig = _ed25519::sign(_::B(text), kp.priv);
    std::cout << "Signature valid: " << _ed25519::verify(_::B(text), sig, kp.pub) << "\n";
    return 0;
}
